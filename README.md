# Task-1:SWYNEX-HR DATA CLEANING AND PREPROCESSING


## 📌 Project Overview

This project focuses on cleaning and preprocessing an HR dataset to improve data quality and make it suitable for further analysis.

The dataset contains employee-related information such as Employee ID, Full Name, Gender, Age, Region, Job Title, Department, Manager/Supervisor, Date of Hire, Employment Status, Work Location, Salary, Pay Grade, Bonus/Allowance, Insurance, Leave Taken, Performance, Training Programs, Skills, and Certifications.

The project performs important data-cleaning tasks such as identifying missing values, detecting duplicate records, checking data consistency, and preparing a clean dataset.

---

## 🎯 Objectives

- Understand the structure of the HR dataset
- Identify missing values
- Find duplicate records
- Check for inconsistent or incorrect data
- Clean and organize the dataset
- Verify the data after cleaning
- Prepare the dataset for further analysis

## 🔄 Data Cleaning Process

### 1. Data Inspection

The dataset is first inspected to understand its rows, columns, data types, and overall structure.

### 2. Finding Missing Values

Missing or empty values are identified in the dataset.

This helps determine which columns require cleaning or further processing.

### 3. Finding Duplicate Values

Duplicate records are checked using the available employee information.

Duplicate records can affect the accuracy of HR analysis, so they should be identified and handled appropriately.

### 4. Checking Data Consistency

The dataset is checked for inconsistent values in fields such as:

- Gender
- Region
- Department
- Job Title
- Employment Status
- Work Location
- Skills
- Certifications

### 5. Date Validation

The **Date of Hire** column is checked to ensure that dates are stored in a consistent format.

### 6. Numerical Data Checking

Numerical columns such as:

- Age
- Salary
- Bonus/Allowance
- Leave Taken
- Performance

are checked for valid and consistent values.

### 7. Final Data Verification

After cleaning, the dataset is reviewed again to verify that the data is properly organized and ready for further analysis.
